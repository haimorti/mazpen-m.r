# מצפן הזכויות שלי – מדריך למבוטחים

חומרי הדרכה למבוטחים על **מצפן הזכויות** החדש באזור האישי של הביטוח הלאומי, המיועד בשלב זה לנפגעי פעולות איבה ולמשפחות שכולות.

## מה יש בריפו

| תיקייה | מה בפנים |
|---|---|
| `source/` | חומר הגלם: המסמך המקורי לעובד (`original/`), התמלול שלו (`madrich-laoved.md`) וצילומי המסך שחולצו ממנו (`screenshots/`). |
| `content/` | התוכן למבוטחים: המדריך המלא (`guide.md`) ושאלות ותשובות (`faq.md`). זהו מקור האמת לטקסטים. |
| `guide/` | המדריך האינטראקטיבי לאתר (`index.html`, RTL, נגיש, תומך במצב כהה). `dist/index.html` הוא אותו דף עם התמונות מוטמעות בתוכו, קובץ אחד שאפשר לשלוח או להעלות כמו שהוא. |
| `video/` | תסריט וסטוריבורד לסרטון (`script.md`) ותוכנית הפקה עם שלוש חלופות (`production-plan.md`). |
| `build/` | סקריפטים שמייצרים מהתסריט שקופיות, כתוביות וטיוטת סרטון. התוצרים ב-`build/out/`. |

## תוצרים מוכנים

- **מדריך לאתר:** `guide/dist/index.html`
- **טיוטת סרטון (אנימטיק, ללא קול, כתוביות צרובות):** `build/out/mazpen-guide-draft.mp4`
- **13 שקופיות 1920×1080 לשליחה כסדרת תמונות:** `build/out/slides/`
- **כתוביות לסרטון:** `build/out/subtitles.srt`
- **קריינות להקלטה:** בתוך `video/script.md`

## לפני פרסום

חפשו בקבצים את הסימון `[[...]]`. אלה מקומות שדורשים השלמה או אימות: פרטי יצירת קשר, קישור לאתר האישי, וכמה תשובות שדורשות אישור מקצועי.

## איך בונים מחדש

```bash
# שקופיות + כתוביות + סרטון (דורש python3, chromium, ffmpeg)
./build/build-video.sh

# המדריך כקובץ אחד עם תמונות מוטמעות
python3 build/inline_guide.py
```

כדי לשנות טקסט בסרטון, עורכים את `build/scenes.json` ומריצים שוב. כדי לשנות טקסט במדריך, עורכים את `guide/index.html` (ואת `content/guide.md` כדי לשמור על התאמה).
